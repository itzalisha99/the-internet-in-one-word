One word for the whole internet, funniest and most fitting wins. My word:

**Brainrot**

The internet's own slang for itself — the whole internet, from comments to videos to memes, is one big brainrot machine. It is funny by itself, true of the internet as a whole, and not the first word anyone reaches for.

## How it works

`main.py` writes the single word to `/output/entry.txt` (8 characters, UTF-8). It first runs `validate()`, which mirrors the bounty gate: 1–30 characters, not only white space, a single word with no spaces. After writing, it reads the file back and confirms it matches the entry byte for byte.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
